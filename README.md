# DataShare — Frontend

Interface utilisateur développée avec Angular pour l'application de partage de fichiers DataShare.

## Stack technique

- Angular 19
- TypeScript
- SCSS
- Vitest (tests unitaires)
- Cypress (tests e2e)

## Prérequis

- Node.js
- Angular CLI

## Installation

```bash
git clone git@github.com:SylvainR-dev/frontend-datashare.git
cd frontend-datashare
npm install
```

## Lancer l'application

```bash
ng serve
```

Application disponible sur `http://localhost:4200`

> Le backend doit être lancé sur `http://localhost:8080`

## Lancer les tests unitaires

```bash
ng test
```

## Lancer les tests e2e

```bash
npx cypress open
```
